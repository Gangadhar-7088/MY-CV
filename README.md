# Gangadhar Behera — Professional Portfolio & CV

A high-performance, futuristic personal portfolio and curriculum vitae built with HTML5, CSS3, and JavaScript.

## Highlights
- **Profile & Visuals**: High-tech orbiting visual with profile imagery and HUD indicators.
- **Ambient Canvas**: Particle network simulation and radial cursor glow.
- **Dynamic Typing**: Interactive typewriter animation showcasing core competencies.
- **Technical Stack**: 4 organized categorized skill panels:
  - Programming & Software (Python, C, C++, Java, JS, HTML5, CSS3, OpenCV, MySQL, Git)
  - IoT & Embedded Systems (Arduino, ESP32, ESP8266, Raspberry Pi, LoRa, MQTT, Sensors, Robotics)
  - Applied Computing & Systems (Computer Applications - PGDCA, Financial Accounting - DCFA, Database Management, System Operations)
  - Exploring & Next-Gen (React, Node.js, YOLOv8, Machine Learning, Deep Learning, Cloud, Figma)
- **Featured Projects**: NETRA-MINE (Mining Telemetry & Vision) and OPTISAFE-AI (PPE Compliance Detection).
- **Academic Milestones**: B.Tech CSE (Nalanda Institute of Technology), +2 Science, and Matriculation.
- **ATS-Ready CV**: Single-page executive PDF curriculum vitae (`Gangadhar_Behera_CV.pdf`).
- **Interactive Contact**: Direct email link, GitHub, LinkedIn, and 1-click clipboard copy.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop displays.

## Local Development
Open `index.html` in your web browser or use VS Code Live Server.

## Deploying to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** (choose `main` / `root`).
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.
